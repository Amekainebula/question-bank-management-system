# 知题 · 题库管理系统

这是软件工程课程设计的第 1 题“题库管理系统”完整实现，依据《刘卫平软件工程课程设计任务书2026》整理了可运行系统和课程设计文档包。项目采用原生 HTML、CSS、JavaScript 和 Node.js 内置静态服务器构建，不依赖第三方包，下载后即可运行。

## 课程设计要求对应关系

系统包含 3 类 Actor：

1. 系统管理员：用户管理、课程管理、题型管理、试题管理、试卷管理、成绩分析。
2. 任课教师：课程管理、题型管理、试题管理、组卷发布、成绩分析。
3. 学生：在线练习、自动判分、成绩查看、错题复习。

已实现的主要功能（CRUD 视为一个完整功能）：

1. 登录与角色权限控制
2. 用户信息增删改查
3. 课程信息增删改查
4. 题型信息增删改查
5. 试题信息增删改查
6. 试题多条件搜索和筛选
7. 试卷手动组卷与总分计算
8. 试卷发布与撤回
9. 学生在线答题与倒计时
10. 客观题自动判分
11. 成绩记录与课程掌握概况
12. 错题本和答案解析

## 运行方式

在项目目录执行：

```bash
npm start
```

浏览器打开 <http://127.0.0.1:4173>。

启动服务后可以执行以下无依赖冒烟检查：

```bash
npm run check
npm run test:smoke
```

也可以直接双击 `index.html` 体验前端页面；使用本地服务器时功能最完整。

## 实现边界与数据说明

当前版本是面向课程设计验收的本地可演示版本：系统首次运行会自动加载示例课程、题型、试题、试卷和成绩数据。新增、编辑、删除和答题记录会保存在浏览器 `localStorage` 中，刷新页面不会丢失。正式生产部署时，应将数据层替换为后端数据库，并补充密码加密、统一认证和并发控制。

若需要恢复初始数据，可以在浏览器开发者工具中删除站点的 `zhiti-question-bank-v1` 和 `zhiti-current-user-v1` 存储项后刷新页面。
