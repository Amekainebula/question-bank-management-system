# 题库管理系统测试报告

## 1 测试目的

验证系统是否覆盖任务书要求的题库管理核心功能，检查三类 Actor 的权限差异，确认从试题录入到学生答题和成绩反馈的主流程可以完成，并记录当前演示版的边界。

## 2 测试环境

| 项目 | 环境 |
| --- | --- |
| 操作系统 | Windows |
| 运行时 | Node.js 24.15.0 |
| 浏览器 | Codex In-app Browser，现代 Chromium 内核 |
| 启动方式 | `npm start` |
| 地址 | `http://127.0.0.1:4173` |
| 数据 | 示例数据 + 浏览器 localStorage |
| 测试日期 | 2026-09-09 |

## 3 测试策略

- 静态检查：检查 JavaScript 和 Node 服务端语法。
- 接口可用性检查：访问首页、脚本和样式资源，确认 HTTP 200。
- 功能测试：按 Actor 执行登录、管理、组卷、答题和成绩场景。
- 回归测试：修正弹窗关闭和导航绑定后，重新执行核心流程。
- 兼容性测试：观察宽屏/窄屏布局下侧栏、表格和表单的可用性。

## 6 缺陷与处理

| 编号 | 缺陷或限制 | 严重性 | 当前处理 |

## 7 测试结论

核心功能测试 20 项全部通过，静态检查和静态资源访问通过。系统满足任务书对题库管理系统的功能性要求，当前版本可以用于课程设计演示和验收；若用于生产环境，需要补充后端身份认证、数据库并发控制和安全审计。
