# 题库管理系统课程设计文档

本目录对应软件工程课程设计从选题到验收的中间产品。任务书明确要求的核心系统功能是课程管理、题型管理、试题管理和试卷生成管理；本项目在此基础上增加用户权限、在线答题、成绩分析和错题复习，使系统形成完整的教学评价闭环。

| 文档 | 对应阶段 | 用途 |
| --- | --- | --- |
| [需求陈述](01-需求陈述.md) | 选题 | 说明背景、范围、目标和价值 |
| [软件需求规格说明书](02-软件需求规格说明书.md) | 需求分析 | 明确 Actor、用例、功能和质量要求 |
| [设计文档](03-设计文档.md) | 软件设计 | 说明架构、模块、数据模型和关键流程 |
| [测试报告](04-测试报告.md) | 系统测试 | 记录测试环境、用例、结果和缺陷 |
| [项目管理与验收](05-项目管理与验收.md) | 项目管理与验收 | 对照课程阶段安排、分工和验收标准 |
| [需求追踪矩阵](06-需求追踪矩阵.md) | 全阶段 | 追踪任务书要求到功能、代码和测试证据 |

## 交付范围

- 可运行系统：项目根目录的 `index.html`、`styles.css`、`app.js` 和 `server.mjs`。
- 启动方式：在项目根目录执行 `npm start`，浏览器访问 `http://127.0.0.1:4173`。
- 演示账号：`admin`、`teacher`、`student`，密码统一为 `123456`。
- 数据保存：浏览器本地 `localStorage`，便于课堂演示和离线验收。

## 使用说明

课程设计提交时建议将本目录导出为 PDF 或打印，同时保留项目源代码和运行截图。姓名、学号、小组成员等课程信息暂未代填，提交前由小组补充。
